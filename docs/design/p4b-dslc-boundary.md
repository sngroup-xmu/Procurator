# P4B / DSLC Boundary

P4-local semantics belong in the p4c fork: parser/control/package handling,
extern lowering, hash semantics, register writes, table semantics,
pipeline-local dependencies, and architecture metadata.

DSLC owns distributed semantics: topology, actor scheduling, queues,
environment modeling, pass-atomic harness generation, projection closure,
wraparound orchestration, certificates, and fallback policy.
